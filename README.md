# 大乐透历史数据分析

一个纯前端的大乐透（超级大乐透，gameNo=85）历史数据分析网站。数据来自中国体彩官网历史开奖接口，全部在浏览器本地渲染，无后端数据库。

## 功能

- **遗漏走势预测预览**：在“号码走势”的预测输入区每行输入 `03 10 14 25 34 + 01 09`，点击“更新走势预览”，在最新一页追加灰色预测行。支持最多20组和前后区切换；各行均基于同一份真实历史独立计算下一期遗漏，不串接为连续开奖、不影响历史统计。虚线分别从最新开奖连接每组按大小排序的对应号码，随“同号走势”开关隐藏；预测仅在本次页面会话保留，可一键清除。输入校验测试：`node data/test_trend_preview.cjs`。

- **下期选号参考**：前后区自选候选池、近 30/50/100 期频次与遗漏、和值/奇偶/大小/跨度/连号条件、多注去重与号码覆盖、全号码随机对照。
- **二码组合遗漏**：前后区分别点选两个号码，显示当前遗漏期数、历史平均 / 最大遗漏、同出次数、最近同出期号与日期。遗漏使用完整历史，平均 / 最大值仅统计两次同出之间的完整间隔；从未同出显示已观察期数，仅同出一次不计算平均 / 最大值。生成方案中的每个号码直接标注单号遗漏，点击可联动组合查询。
- **方案保存与复盘**：保存在当前浏览器，关联基准期之后首期开奖，自动展示每注前后区命中数；最多保留 100 份。清理浏览器数据会丢失方案。
- **历史回测**：固定使用每期之前的历史构建频次前 15/6 候选池，应用当前条件，对照同注数随机选号；报告平均命中和跳过期数。历史结果不能证明未来优势，不提供中奖概率或收益承诺。运行离线测试：`node data/test_selection.cjs`。

- **总览**：总期数、起止期、最新开奖号码、最大销售额/奖池
- **号码走势**：传统彩票走势表（每期一行、号码为列、显示遗漏；1/2/3 分区；30 期一组翻页）；可切「走势线」视图
- **和值 / 012路 / 奇偶大小 / 重号**：数字连线走势表（30 期一组翻页）+ 历史分布图
- **遗漏冷热**、**奖池/销售额**走势
- 遗漏表数字连线（每个号码列把开出点纵向串起）

## 目录结构

```
.
├── data/                  # 数据抓取与生成脚本
│   ├── gather_dlt.py      # 抓取体彩官网历史开奖 -> dlt_history.csv(.xlsx)
│   ├── gen_data.py        # CSV -> ../docs/data.js（网站加载的数据）
│   ├── update_data.py     # 一键更新：抓取 + 生成
│   └── update.bat         # Windows 双击更新
└── docs/               # 网站（静态）
    ├── index.html
    ├── app.js
    ├── data.js            # ★ 网站实际加载的数据（window.DLT_DATA）
    ├── echarts.min.js     # 本地图表库
    ├── serve.py           # 本地后端：托管网页 + 打开即更新接口
    └── 启动网站.bat        # Windows 双击启动
```

## 本地运行

方式一（推荐，打开即更新数据）：
> 双击 `docs/启动网站.bat`，自动起服务并打开 `http://localhost:8000`。
> 打开网页时后端会自动检查/拉取最新开奖数据（无新期则秒回）。

方式二（手动起服务）：
```bash
cd docs
python serve.py
# 浏览器访问 http://localhost:8000
```

方式三（纯静态，不自动更新）：
直接双击 `docs/index.html` 用浏览器打开，使用的是当前 `data.js` 已有数据。

## 更新数据

大乐透每周一、三、六晚开奖，开奖后更新一次即可：
```bash
cd data
python update_data.py      # = gather_dlt.py + gen_data.py
```
或双击 `data/update.bat`。`gen_data.py` 会顺带给 `index.html` 里 `data.js` 的引用加版本号，避免浏览器缓存旧数据。

## 部署到公网

> 本项目是纯静态站点（无后端数据库），只需把 `docs/` 下的前端文件发布出去即可。
> 部署后「打开即更新」功能不可用（那依赖本地后端），数据更新改用下面的「自动更新」方案。

### 方式一：GitHub Pages（推荐，免服务器 + 自动更新）

**第 1 步：开启 Pages（只做一次）**
1. 打开仓库 https://github.com/crfmoon/lottery → **Settings** → 左侧 **Pages**。
2. **Build and deployment → Source** 选 **Deploy from a branch**。
3. **Branch** 选 `main`，**目录** 选 `/docs`，点 **Save**。
4. 稍等一两分钟，页面顶部会出现 `https://crfmoon.github.io/lottery/` 的访问地址，点开即见网站。

**第 2 步：数据自动更新（已配置，免维护）**
仓库里的 `.github/workflows/update.yml` 会在 **开奖次日（周二/四/日）北京时间 00:30** 自动更新，并在 **08:30** 补查：
- 连体彩官网抓最新开奖 → 生成 `docs/data.js` → 提交回 `main` 分支；
- 因 Pages 是从 `main` 分支的 `/docs` 发布，提交后网站**自动重新发布**，访客看到的永远是最新数据。

你完全不用手动干预。若想立刻更新（比如开奖当晚），可到仓库 **Actions** 页手动 **Run workflow**。

每次检查都会回查至少最近五期，补齐同一期后续修订的销售额、奖池和奖级明细；有较多缺失期时自动继续翻页。写入前校验期号、日期、号码范围和重复号码，异常时保留原 CSV。

页面分别展示数据变更时间与最近检查时间（北京时间），检查失败会提示当前展示上次成功的数据。检查状态保存在 `docs/update-status.json`；无数据变化时不重写 CSV、`data.js` 或缓存版本，但会提交最新检查状态。抓取失败也会尝试发布失败状态，任务仍标记失败。

运行离线校验：`python -m unittest discover -s data -p "test_*.py"`。

> 注意：GitHub 的境外 runner 访问国内体彩接口偶尔会偏慢/失败。若某次自动更新失败，本地跑
> `data/update.bat`（或 `python data/update_data.py`）更新后 `git push` 即可，网站会随之刷新。

**第 3 步（可选）：绑定自己的域名**
在 Settings → Pages → **Custom domain** 填你的域名，并按提示加一条 CNAME 解析即可（仓库会自动提交 `CNAME` 文件）。

### 方式二：Vercel（最省心，部署体验好）
1. 打开 [vercel.com](https://vercel.com)，用 GitHub 登录并 **Import** 本仓库。
2. 本仓库已含 `vercel.json`（输出目录 `docs`），无需额外配置，直接 **Deploy**。
3. 部署后给一个 `xxx.vercel.app` 域名；之后本地更新数据 `git push` 即自动重新部署。
   （Vercel 无内置定时抓取，数据更新靠你本地 push，或用上面的 GitHub Actions 推送触发。）

### 方式三：Nginx / 对象存储 + CDN（需自有服务器）
把 `docs/` 整目录作为静态根发布即可，更新方式同「本地更新后重新同步」。

### 带后端（VPS，对外提供服务）
若想保留「打开网页即更新」体验并对外提供，可在云服务器用 Gunicorn + Nginx 托管 `docs/serve.py`，
并把「打开即更新」改为服务端定时更新 + 限流 + HTTPS，避免每个访客都触发抓取。

## 合规声明

数据来源于中国体彩官网公开历史开奖接口，仅用于个人娱乐与研究参考；历史统计不能预测未来开奖。
公网大规模提供请注意官网接口使用条款及频率限制。
