预测号码预览

每行一组：前区5个号码 + 后区2个号码，最多20组。各组是同一期的独立备选，不作为连续开奖，不写入历史数据。仅在最新一页的遗漏表中追加预览；虚线按号码从小到大的位置连接最新开奖与各组。

合并表：红球为前区，蓝球为后区，灰球为预测；遗漏数字可隐藏。前区连接相邻期同号，后区按大小排序对应连接；高亮开关显示前区邻期差1及同号。各预测组分别从最新开奖按排序位置虚线延伸，互不串联。单区表保留原有规律线；独立走势线视图需选择前区或后区。

区域：
